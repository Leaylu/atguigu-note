# Agent 应用与 Skills 开发实战：课程大纲

课程分为技术篇与项目实战篇。技术篇通过简单案例理解工具和扩展能力；项目实战篇以 Codex 为统一入口，将企业已有程序、接口、数据库与工作流接入 Agent。

面向具备基本电脑操作能力的学习者，以及希望将 Agent 应用于企业工作的 IT 工程师。Codex 提供 OpenAI 与 DeepSeek 两条模型路线。技术篇以电商 IT 工程师为背景：使用Word整理数千条运维工单的值班交接，使用Excel核对订单、支付与履约等多表业务数据，用 Python 检查导出数据，再将排查方法制作成 Skills。
