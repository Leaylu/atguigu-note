# 审查与修订示例

下列错误写法用于说明技能审查的方法。

| 错误片段 | 为什么有问题 | 修订方向 |
| --- | --- | --- |
| 本技能处理所有办公与开发任务 | 与电商订单分析范围不符 | 描述具体输入、任务和输出 |
| 已支付口径固定显示6,352单 | 把样例答案写成固定规则 | 按清洗后的已支付和已发货状态动态统计 |
| 同一编号只保留第一条 | 会隐藏内容冲突 | 完全重复才合并，冲突隔离全部版本并报告范围 |
| 没有反馈时生成三条客户好评 | 编造资料 | 说明未提供反馈 |
| 运行 scripts/report.py 生成全部文件 | 本轮没有提供该脚本 | 去掉无依据引用，说明所需工具 |
| 保存文件即代表公式与排版全部通过 | 将未执行检查当作已通过 | 分别记录生成、计算和版式检查状态 |

审查时先找到对应原文，再说明影响，最后提出局部修改。针对文件中实际存在的问题进行修订。

运行条件齐备后，使用第三章输入检查基础统计，再删除反馈内容检查缺失分支。预期与实际分开记录，尚未执行的场景明确标记未验证。
