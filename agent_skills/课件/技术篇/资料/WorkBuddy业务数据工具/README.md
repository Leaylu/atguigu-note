# WorkBuddy业务数据生成与校验

配套CSV已生成，可以直接使用，不需要先运行脚本或学习Python。脚本用于重新生成同样数据或更换随机样本，均只使用Python标准库。

默认种子20261012，基准时间2026-10-12T12:00:00+08:00。随机内容包括门店、商品、金额、状态、时间和工单分布；重复、冲突、缺失等案例条件按确定规则植入，便于观察业务处理分支。

在本工具目录打开终端：

~~~powershell
python generate_case_data.py --output 新一批业务数据 --seed 20261012
python verify_case_data.py --root 新一批业务数据
~~~

目标目录必须尚不存在，脚本拒绝覆盖旧数据。输出包含第02章与第03章的输入CSV、预期指标、异常核对清单、SHA256与生成清单。相同种子与相同Python运行环境得到相同文件；换种子后，以新生成的预期指标为准，不沿用讲义中的固定统计数字。

若希望校验已经随课程交付的数据，在本工具目录执行：

~~~powershell
python verify_case_data.py --root ..
~~~

生成器计算预期值，校验器使用独立SQLite查询复核去重、冲突、关联、金额、超时与Top20，不导入生成器的统计函数。

重新生成的目录只含数据与核对结果。使用WorkBuddy前，从现有第02/03章输入资料目录分别复制对应的“案例说明与口径.md”及背景/反馈文件，不把结果核对目录交给Agent。生成器不制作Word/Excel成品，这两类成果由章节中的WorkBuddy流程生成。
