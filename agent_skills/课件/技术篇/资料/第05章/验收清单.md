# 第五章验收清单

在项目根目录运行，每条命令后用 PowerShell 的 $LASTEXITCODE 查看退出码。首次输出目录必须不存在。

| 命令或操作 | 预期 |
| --- | --- |
| py main.py | 匹配 8，已支付 6、待支付 1、已取消 1；退出码 0 |
| py main.py --product "机械键盘" | 匹配 4，全量已支付 6；退出码 0 |
| py main.py --product "机械键盘" --status "已支付" | 匹配 3；退出码 0 |
| py main.py --product "蓝牙耳机" --status "已取消" | 匹配 0；退出码 0 |
| py main.py --input-dir "批量输入" | 原始 16，非法 1，重复额外 2，冲突编号 1、版本 2，有效 11；退出码 1 |
| py main.py --input-dir "批量输入" --product "机械键盘" --status "已支付" --output-dir "输出/键盘核对-01" | O003、O006、O008、O011；问题 5 行；退出码 1 |
| 再执行上一命令 | 拒绝覆盖，原文件字节不变；退出码 2 |
| py main.py --input-dir "批量输入" --product "不存在的商品" --output-dir "输出/无匹配-01" | 结果 CSV 仅表头，问题仍 5 行；退出码 1 |
| py main.py --input-dir "边界输入/空数组" --output-dir "输出/空数组-01" | 数量均 0，两份 CSV 仅表头；退出码 0 |
| py main.py --input-dir "边界输入/格式损坏" --output-dir "输出/损坏-01" | 提示损坏订单.json 格式错误，不创建输出；退出码 2 |
| py main.py --input-dir "不存在的输入目录" | 路径错误；退出码 2 |
| 新建不含 JSON 的目录，再以 --input-dir 指定 | 提示没有输入文件；退出码 2 |

## 样例的人工核对依据

- 首批 8 条，补充 8 条。
- 重复额外记录：补充第 1 条 O003、第 2 条 O007。
- 冲突：首批第 5 条 O005 待支付，补充第 3 条 O005 已支付；均排除。
- 非法：补充第 7 条 O012 缺少 product。
- 渠道缺失：补充第 5 条 O010，保留并显示未填写。
- 有效编号：O001、O002、O003、O004、O006、O007、O008、O009、O010、O011、O013。
- 有效状态：已支付 8、待支付 2、已取消 1。
- 各商品已支付：机械键盘 4、蓝牙耳机 4。
- 问题清单：重复 2 行、冲突 2 行、非法 1 行。
