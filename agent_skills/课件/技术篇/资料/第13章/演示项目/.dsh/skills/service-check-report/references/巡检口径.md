# 巡检口径

输入为非空 JSON 数组，字段恰好为 id、service、path、status_code、elapsed_ms。
前三项为非空字符串；status_code 是 100—599 的整数；elapsed_ms 为非负整数。
布尔值不视为整数；id 不允许重复。任一记录非法即停止，不输出部分汇总。

依次分类，每条记录只属于一类：
1. status_code 不在 200—299：失败。
2. 状态为 2xx 且 elapsed_ms >= 1000：慢响应。
3. 状态为 2xx 且 elapsed_ms < 1000：正常。

例如 503 且耗时 2000ms 只计为失败，不再计慢响应。
这是本演示的固定阈值，真实环境须按接口SLA调整。
总数按检查记录计算，不等同于服务数量、订单数量或服务可用率。
只有观测数据，无请求体、错误日志与依赖链，不能认定数据库、支付渠道等为根因。
不访问 path 对应的真实服务，也不重放请求。
