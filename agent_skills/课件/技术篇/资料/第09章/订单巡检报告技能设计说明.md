# 订单巡检报告技能设计说明

## 范围与输入

复用第三章[五张CSV与业务资料](../第03章/输入资料)，按[业务口径](../第03章/输入资料/案例说明与口径.md)生成Excel与Word核对成果。只分析导出数据，不修改生产订单、退款、发送通知或确认损失。

基准时间由任务明确指定；固定样本为2026-10-12T12:00:00+08:00。缺少关键文件或字段时说明缺口；反馈可缺失，但不可编造。

## 规则

1. 完全重复行去重；同编号冲突隔离全部版本；数量、状态或SKU非法则隔离整单，保留审计。
2. 渠道缺失保留为未填写。清洗行数守恒，统计只代表明确的可用范围。
3. 支付先去重并按order_id聚合，再关联订单，避免一对多放大；库存按store+sku关联。
4. 已支付口径包含已支付与已发货；金额按整数分核对，展示元时除以100。
5. 支付标签互斥；履约超时与库存风险按第三章口径计算。跨类型异常集合可能交叉，不能直接相加。
6. 孤立记录与关联已隔离订单分开。缺少流水不证明未到账，当前库存不证明历史缺货。

## 输出与流程

盘点 → 清洗审计 → 聚合关联 → 异常核对 → Excel公式图表 → Word报告 → 跨文件检查。

生成交易核对工作簿.xlsx，含原始数据、清洗明细、异常、门店/渠道汇总与趋势；生成电商交易核对报告.docx，含范围、审计、证据、建议和限制。

保留原始数据，重名另存新版本。使用真实可编辑办公文件，核对公式值与版式；工具缺失时说明未完成部分，不把说明文件冒充成果。

## 验收

固定样本8,150行，去除120行完全重复、60行冲突版本和40条非法订单后，可用7,930单；已支付口径6,352单，支付异常79单，超时未发货2,335单，其中库存不足905单。

换种子重新计算；删除反馈后仍可核对数据；缺少关键CSV不能宣称完成全流程；重复执行不能覆盖旧成果。预期答案不放入业务输入或Skill资源中。
