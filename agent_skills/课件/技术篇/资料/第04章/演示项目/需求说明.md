# Python 电商订单统计工具

使用 Python 3 标准库，生成 main.py 和 README.md，不安装第三方依赖。

## 输入与运行

默认以 UTF-8 读取 main.py 同目录的订单数据.json，不能依赖终端当前目录定位输入。保留源文件。

支持 --product 和 --status 可选参数；未提供表示全部，组合条件使用“同时满足”。输出简体中文。

## 输出内容

每次运行显示全量统计：总记录、已支付订单、待支付、已取消。随后显示筛选条件、匹配数量及记录列表。列表包含编号、商品、状态和渠道。无匹配时给出中文提示。

## 统计规则

输入已去重，共 8 条。已支付订单仅统计“已支付”，统计单位为记录，不宣称是独立买家数。筛选只影响列表与匹配数，不影响全量统计。渠道“未填写”保留原值。不推断销售额、履约或转化率。

## 错误与说明

文件缺失或 JSON 格式错误时给出清楚的中文提示，并以非零状态退出。README 说明 Python 环境、运行命令、参数示例和已验证范围。无需网页、数据库、网络请求或部署。

## 核对依据

全量 8 条，已支付订单 6、待支付 1、已取消 1。两类商品各 4 条记录，各 3 条已支付订单。机械键盘与已支付组合筛选得到 3 条；蓝牙耳机与已取消组合筛选得到 0 条。不加参数恢复显示全部记录。

本工具用于电商 IT 日常巡检中的订单导出核对，不连接生产系统。每条样例订单只包含一个商品；已支付数量按输入状态计算，不能代替支付流水对账。
