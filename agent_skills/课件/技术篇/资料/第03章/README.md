# 第三章配套资料：订单、支付与履约联合核对

主案例包含 **8,150行订单、6,470行支付流水、3,831行发货记录、80个商品和240条门店库存**。CSV使用UTF-8 BOM，方便Excel/WPS读取中文。

将[输入资料](输入资料)复制到独立工作空间，先按口径清洗与关联，再由WorkBuddy生成Excel和Word成果。不要把答案文件混入分析输入。
