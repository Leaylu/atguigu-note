# 技术篇：企业级 Agent 应用与 Skills 开发

本篇以虚构电商公司的 IT 工程师为背景：日常整理故障工单，核对订单导出数据，编写 Python 检查工具，并将稳定的排查方法整理为 Skills。WorkBuddy处理数千条运维工单和订单数据，生成Word值班交接报告与多表Excel核对工作簿；Codex 负责 Python 程序与技能文件；MCP 用于查询技术资料。

## 学习准备

具备基本电脑操作能力即可开始。办公案例需要能够打开 Word、Excel 文件的软件；Python 案例使用 Python 3。命令以 Windows PowerShell 为例。Codex 可选择 OpenAI 或 DeepSeek 模型路线，按所选路线准备账号与配置。

[案例与资料索引](案例与资料索引.md)可以快速查看每个案例的输入、成果与检查重点。

## 学习路径

工具使用 → Python 开发与调试 → MCP 接入 → Skills 使用与制作 → DeepSeek Harness。

前五章认识工作方式和工具；第六章认识 MCP；第七至十二章集中学习 Skills；第十三章认识另一种 Agent 运行框架。各章通过概念与案例认识关键能力；第二、三章使用数千条随机业务数据演示完整办公任务。
