# 技术篇案例与资料索引

案例统一设定在一家虚构电商公司，使用者是 IT 工程师。日常工作包括整理故障工单、核对订单导出、排查字段异常、开发辅助脚本和维护团队技能。可按对应讲义查看输入、操作请求和预期结果。

## 怎样使用配套文件

`资料/第XX章/README.md` 说明该章文件用途。将需要的输入复制到独立工作目录，在对应 Agent 中打开该目录；命令涉及相对路径时，先确认讲义要求的终端位置。

第四、五章的 main.py 在案例过程中由 Codex 生成；第十二章的 replenish.py 是独立补货计算程序，第十三章的 summarize_checks.py 是巡检汇总程序。各程序的输入规则和输出用途不同，不能互相替换命令。

第十、十二、十三章提供完整技能源目录。安装时复制整个目录，保留引用的资料、模板和脚本。结果核对表用于对照输出，不作为业务处理输入。

第二、三章的随机数据已经落盘，默认种子为20261012；[生成与校验工具](资料/WorkBuddy业务数据工具/README.md)可重新生成或更换批次。将输入资料与结果核对目录分开，避免Agent直接读取预期答案。

## 统一的结果检查方式

先确认使用了正确输入，再观察工具执行，最后打开成果核对。文中的数量属于指定样例的预期；更换输入后应重新计算。

Word 检查内容与可编辑性；Excel 检查公式与图表引用；Python 检查命令、输出和错误处理；MCP 检查连接与调用；Skills 检查发现、读取、执行与结果。
