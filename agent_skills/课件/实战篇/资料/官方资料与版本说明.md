## Codex 接入资料

[Codex MCP配置](https://learn.chatgpt.com/docs/extend/mcp#streamable-http-servers)说明HTTP端点和bearer_token_env_var。课堂采用Streamable HTTP（127.0.0.1:8001/mcp），MCP通过业务HTTP API访问数据库；stdio入口保留测试。

[Skills 与工具连接的分工](https://developers.openai.com/plugins/concepts/skills)用于理解技能说明与工具能力之间的关系。工程 Skill 位于 `.agents/skills/ecommerce-order-investigation`；工具注册后还需单独检查技能发现情况。

## 版本边界

MCP 官方 SDK 1.x 的入口为 `mcp.server.fastmcp.FastMCP`。SDK 2.x 和独立 `fastmcp` 包有各自接口，升级应对照对应文档修改并重新验证，不混用导入路径和启动参数。

LangGraph 通过同一 thread_id 找到检查点，恢复节点可能重新执行中断前的代码，因此写入仍需幂等控制。图中的节点也可以是普通 Python 函数，不要求每个节点都调用模型。

MySQL 8.4 标签随维护版本更新。正式交付需要进一步锁定容器镜像摘要，并保留数据库迁移与回滚方案。
